Python-скрипт для замера скорости и стабильности скачивания файла.

## Что делает скрипт:
- Выполняет 10 последовательных HTTP-запросов к указанному URL с ожиданием полного ответа на каждый запрос.
- Обходит кэширование (добавляет уникальный query-параметр и заголовки `Cache-Control` / `Pragma`).
- Сохраняет скачанный файл в папку со скриптом.
- Выводит по каждому запросу код ответа, размер (МБ) и затраченное время (с).
- В конце рассчитывает среднее время запроса, общий объём скачанных данных (МБ) и среднюю скорость скачивания (Мбит/с).

## Файлы
- `download.py` — основной скрипт (URL задаётся в переменной `url` внутри файла).
- `requirements.txt` — список зависимостей (`requests`, `beautifulsoup4`).
